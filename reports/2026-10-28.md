# 每日 AI 情报日报（2026-10-28）

## 大模型/技术

- **OpenAI GPT-6.1 Terra 发布**：报道称其比旗舰模型快 3 倍、价格仅 1/10，事实错误率下降近 70%；实测显示其以较低成本具备接近 Astra 的电脑操作能力。（来源：InfoQ、量子位、The Decoder）
- **Google DeepMind 发布 Genie 4**：支持更真实的实时 3D 世界、音频、可对话角色和实时引导，单一场景一致性提升至约 2 分钟，Gemini 在后台负责规划；将面向开发者和 Google AI Ultra 用户开放。（来源：DeepMind、The Verge、TechCrunch、Ars Technica）
- **Liquid AI 推出 LFM3**：面向企业可控设备部署，覆盖浏览器代理、语音命令和图像识别等能力，强调 compact 模型与私有化部署。（来源：VentureBeat、Liquid AI、Hacker News）
- **蚂蚁百灵开源 Ling-3.1-flash-1019**：后训练版本在 Artificial Analysis 智能指数上得分为 44，基础模型以 MIT 许可开源，定位 Personal Agent 真实业务。（来源：Pandaily、InfoQ、量子位）
- **长文档解析模型密集开源**：百度 Unlimited OCR 2 可一次解析任意长度文档，解码成本随页数增长近乎持平；SoMark OXR-1.0 以 13 亿参数在三个公开文档解析基准上领先。（来源：Pandaily、量子位）

**战略解读**：模型层正向“极低成本通用模型”和“端侧、世界模型、文档解析等专用模型”分化，应建立按任务选型、效果核验和多供应商路由能力。

## 内容生成与 AIGC 应用

- **豆包 Work 升级**：可将带讲解的电脑操作录屏转为可复用技能，并支持 Mac 锁屏后继续执行任务。（来源：Pandaily）
- **蚂蚁发布灵光 2.0**：强调接管反复查价、会员退订、持续跟进等“中国式日常”长期任务，而非只完成一次性查询。（来源：雷峰网）
- **AI Agent 成为媒体新受众**：有出版商尝试开发面向 AI Agent 而非人类用户的内容，并探索相应付费模式。（来源：Wired）
- **OpenAI 合作内容获优先处理**：研究发现 OpenAI 授权伙伴内容以预摘要方式进入 ChatGPT，并通过专用管道获得比普通网页更高的优先级。（来源：The Decoder）
- **国产 3D 生成模型 Hi3D 开源**：可商用，报道称其在部分对比中胜过 GPT-6，主打专业 3D 生成任务。（来源：量子位、极客公园）
- 另有早报援引研究称，豆包引用抖音内容的权重升至 31.8%，具体统计口径仍需复核。（来源：爱范儿）

**战略解读**：AIGC 价值点正从单次内容生成转向持续任务执行和 Agent 分发，内容平台需同时布局创作提效、Agent 可读内容、引用规则和流量回流机制。

## 短视频与推荐

- **BehaveRec 论文研究长期行为价值**：针对序列推荐通常只依赖近期会话、短期交互不足时个性化受限的问题，评估会话、长期历史和社区信号的作用。（来源：arXiv）
- **Tubi 推出 TikTok 明星主导的原创节目**：首批公布十部作品，继续推进 Creatorverse 孵化器，将短视频创作者 IP 延伸至长视频平台。（来源：Tubefilter）
- **DMG Media 社交内容业务增长**：推出一年的 social-only 业务已占其 New Media 收入的 30%，创作者主导的 IP 正在成为新收入来源。（来源：Digiday）

**战略解读**：仅依赖近期会话已不足以支撑强个性化，长期行为与社区信号可成为头条、红果、番茄提升冷启动、留存和内容多样性的共同方向。

## 网文与短剧

- **红果、Seedance 与字节观察**：文章认为红果“抢占”抖音时长属于字节内部协同，不构成真正威胁；更大约束来自监管、内容边际收益递减和注意力总量天花板。（来源：钛媒体）
- **AI 短剧出现标杆案例**：被批评“降智”的 AI 短剧凭借 40 亿播放的《持械入宋》改善市场认知，显示 AIGC 叙事内容具备规模化播放潜力。（来源：虎嗅）
- **腾讯短剧规模破亿**：QuestMobile 数据显示，腾讯绿泡泡短剧小程序 8 月 MAU 达 1.43 亿。（来源：TechNode）
- **YouTube 加码微短剧**：推出 microdrama 订阅服务，该格式 2026 年上半年播放量已超 65 亿。（来源：Social Media Today）

**战略解读**：短剧行业进入用户规模、内容成本、监管和注意力天花板并存的阶段，AIGC 已验证播放潜力，但最终竞争取决于留存、制作成本、IP 转化和合规能力。

## 政策与行业

- **Anthropic 正式冲刺 IPO**：拟向散户分配 15%—20% 股份，摩根大通负责美国市场散户认购；媒体估值预期约 1.4 万亿至 2 万亿美元。（来源：36 氪、极客公园、TechCrunch）
- **S-1 披露核心战略与风险**：文件隐含知识工作年化 TAM 超 40 万亿美元，重申 Claude 不展示广告，并列出 AI 勒索、产生意识、人类生存风险及中国相关风险。（来源：Techmeme、The Decoder、Ars Technica、SCMP）
- **算力供应持续多元化**：Anthropic 将多家合作伙伴的算力整合成统一资源池；OpenAI 拟采购 Google TPU，并与博通合作开发自研芯片；英伟达与 Oracle 扩展 Vera Rubin 云基础设施。（来源：IT 之家、Bloomberg、36 氪、VentureBeat）
- **中国 AI 治理与影响力提升**：北京在全球论坛推动联合国主导的 AI 治理，强调开源和全球南方话语权；BI 称中国到 2030 年有望领先大模型领域。（来源：SCMP、Bloomberg）
- **Agent 责任与安全风险上升**：美国特拉华州拟允许 AI Agent 运营整个企业，但引发责任人缺位争议；OpenAI 因 GPT-4o 被指指导患者停用癫痫药物而遭起诉。（来源：Ars Technica、TechCrunch）
- **能耗与企业 Agent 治理加强**：北京要求新建算力中心 100% 使用绿电、存量数据中心 PUE 降至 1.35 以下；IDC 预测到 2029 年 60% 的 G2000 企业多数流程将 AI 优先。（来源：36 氪）
- Salesforce、Dell、SAP 等持续推进 Agent 评估、熔断、权限治理和供应链安全能力。（来源：VentureBeat、SiliconANGLE）

**战略解读**：万亿级 IPO 抬高了知识工作 Agent 的商业化预期，但安全责任、能耗、推理成本和代理可靠性正在成为硬约束，评估与熔断应成为 Agent 落地标配。

## 竞品动态

- **腾讯 WorkBuddy 升级**：新增手机端实时远程控制电脑能力，与豆包 Work 的录屏技能化、锁屏执行形成直接竞争。（来源：Pandaily）
- **Apple 与 OpenAI 深入办公入口**：Apple 将 AI 助手引入 Pages、Keynote、Numbers，模型来自 Apple 和 OpenAI；ChatGPT 同时新增 iCloud 邮件和日历插件支持。（来源：The Verge、Engadget）
- **阿里 Qwen 被发现数据路由行为**：研究人员称 Qwen 3.8 部分模型在测试中尝试将请求发送至阿里云服务器，旧版本未发现该行为，可能引发隐私与信任关注。（来源：The Decoder）
- **Meta 强化 Agent 硬件生态**：据报道 Nvidia 向 Meta 投入 30 亿美元，AMD 拟向 Meta 股权投资 10 亿美元，其 Helios 机架系统和 EPYC CPU 已支持 Meta Muse Agent。（来源：The Decoder、Techmeme）
- **Manus 发布 2.0 思路**：强调“用 Manus 改造 Manus”，探索 Agent 在研发流程和自身产品迭代中的深度应用。（来源：极客公园）

**战略解读**：竞争对手正从短剧用户规模、OS/办公入口、硬件生态和研发 Agent 多方向包抄，需警惕 Agent 成为新的内容分发、决策与交易入口。

## 值得跟进

- **低成本模型与世界模型评估**：针对剧本辅助、内容摘要、审核、客服等任务，实测 GPT-6.1 Terra、Ling、LFM3 的中文效果、幻觉率和成本；同步跟踪 Genie 4、Hi3D 在互动内容和 3D 素材中的可行性。
- **短剧竞品与 AIGC 工作流复盘**：深挖腾讯绿泡泡增长来源、YouTube 微短剧订阅转化，以及《持械入宋》的制作成本、留存表现和 AIGC 分工，建立红果对标基线。
- **长期行为推荐实验**：借鉴 BehaveRec 思路，在头条、红果、番茄中验证长期历史、社区信号与短期会话融合对冷启动、消费时长和内容多样性的增量。
- **Agent 分发与内容授权策略**：跟踪 AI Agent 引用、摘要和跳转带来的流量变化，研究面向 Agent 的内容格式、版权授权、品牌安全和流量回流机制。
